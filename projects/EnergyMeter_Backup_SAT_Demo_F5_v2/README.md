# EnergyMeter — резервное копирование и SAT (вариант 15)

Готовый учебный проект для **Visual Studio 2022 и .NET 8**, запускается по F5 без аргументов, без базы данных и внешнего сервера. Исправлена возможная блокировка SQLite при вычислении SHA-256 в Windows.

## Запуск

1. Распакуйте ZIP полностью.
2. Откройте **EnergyMeter.BackupSAT.Demo.sln** в Visual Studio.
3. Если появится запрос восстановления NuGet-пакетов, дождитесь завершения (при первой установке может потребоваться интернет).
4. Нажмите **F5**.
5. Дождитесь сообщения **«ИТОГ: ВСЕ 8 ДЕМО-ТЕСТОВ ПРОЙДЕНЫ»**.
6. Сохраните скриншот консоли и найдите в ней строку с папкой DemoOutput.

## Что создаётся

В каталоге EnergyMeter.BackupSAT.Demo/bin/Debug/net8.0/DemoOutput/<дата-время>/:

- source/energymeter-demo.sqlite — учебная SQLite-база, пять показаний;
- backups/energymeter-backup.sqlite — реальная резервная копия через SQLite Online Backup API;
- backups/energymeter-backup.sqlite.sha256.txt — SHA-256 резервного файла;
- restore-test/restored.sqlite — отдельный восстановленный экземпляр;
- demo-report.txt — результаты 8 автоматических проверок PASS/FAIL;
- SAT_Protocol.md — протокол приёмочных испытаний SAT-01—SAT-07.

САТ-протокол не подделывает проверку остальных модулей: **SAT-07** отмечается по результатам текущего восстановления, а **SAT-01—SAT-06** оставлены «Не проведено», поскольку нужны результаты других тестов.

## Резервная копия вашей настоящей базы

Если хотите проверить копирование базы из EnergyMeter Offline, выполните проект с аргументами:

    --source "C:\полный\путь\к\energymeter-demo.sqlite"

В Visual Studio: «Свойства проекта» → «Отладка» → «Аргументы командной строки». Первый запуск и демонстрация работают без этих аргументов. Исходная база в этом режиме открывается для чтения и **не перезаписывается**.

## Дополнительные PowerShell-скрипты

В папке Scripts находятся:

1. Backup-EnergyMeter.ps1 — копирование **остановленной** SQLite-базы и запись SHA-256.
2. New-SAT-Protocol.ps1 — создание исходного шаблона приёмочных испытаний.

Пример запуска (из PowerShell, находясь в папке распакованного проекта):

    .\Scripts\Backup-EnergyMeter.ps1 -SourceDb "C:\полный\путь\к\базе.sqlite" -BackupDir "C:\Users\Kraken\source\repos\EnergyMeterBackups"
    .\Scripts\New-SAT-Protocol.ps1 -Release "1.0.0" -OutputFile ".\SAT_Protocol_Manual.md"

**Не вставляйте строку param(...) отдельно в PowerShell.** Открывайте готовые .ps1-файлы как скрипты с аргументами.

PowerShell-копирование обычным Copy-Item допускается только после остановки приложения, работающего с SQLite. Для работающей базы безопаснее использовать C#-проект: он применяет специальный SQLite Online Backup API.

## Скриншоты для работы

1. Visual Studio + консоль — восемь результатов PASS.
2. Папка backups с SQLite и SHA-256.
3. Папка restore-test с восстановленной SQLite.
4. Файл demo-report.txt.
5. Протокол SAT_Protocol.md.

В отчёте нельзя утверждать, что все семь SAT-испытаний уже проведены: этот проект действительно проверяет резервное копирование и восстановление, а другие пункты подтверждаются отдельно демонстрациями API, Offline и дополнительными испытаниями.
