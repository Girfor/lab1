# ПР4/ПР5/ПР7 — защищенный рефакторинг EnergyMeter

Технологии: ASP.NET Core Web API, C# .NET 8, in-memory storage.

## Реализовано
- контроллер, отдельный сервис и модели;
- диапазон показаний 0..999999.999 kWh, точность 0.001;
- валидация даты, проверка прав к `meterId`, идемпотентность;
- cookie-аутентификация и проверка CSRF-токенов на POST;
- Swagger доступен только в Development;
- политика роли `MeterWriter`.

Демо-счетчик: `11111111-1111-1111-1111-111111111111`.

## Запуск
1. Установить .NET 8 SDK или открыть проект в Visual Studio.
2. В PowerShell:
```powershell
dotnet dev-certs https --trust
dotnet run --project EnergyMeter.PR4.Refactored.csproj
```
3. Открыть `https://localhost:7204/swagger`.

Для локальной демонстрации используется пользователь `operator`.
Пароль задайте самостоятельно через переменную окружения `Demo__Password` до запуска.
Пароль намеренно не включён в файлы репозитория. В Production демо-вход отключён.

## Запросы
1. В Swagger выполнить `GET /api/auth/csrf`, скопировать значение `token` из ответа.
2. Выполнить `POST /api/auth/login`: вставить полученное значение в поле
   заголовка `X-CSRF-TOKEN`, указать логин и пароль:
```json
{"username":"operator","password":"<ваш пароль из Demo__Password>"}
```
3. **После входа снова выполнить `GET /api/auth/csrf`** и скопировать
   обновлённый токен для уже авторизованного пользователя.
4. Выполнить `POST /api/meters/11111111-1111-1111-1111-111111111111/readings`.
   В поле заголовка `X-CSRF-TOKEN` вставить обновлённый токен, а в тело:
```json
{"kwh":12.5,"measuredAt":"2026-11-05T10:00:00Z"}
```
   **Обязательно** замените дату на текущую в UTC (не позднее текущего времени + 5 минут).
5. Проверить сохранение через `GET /api/meters/11111111-1111-1111-1111-111111111111/readings`.

Показания доступны только после входа. Значение `meterId` фиксировано для
учебного демо; произвольный GUID не существует и даст ответ `404`.

Для реальной эксплуатации нужны база данных, управление пользователями,
безопасное хранение секретов, отдельные роли и аудит. Это учебный прототип.
