# ПР6 — xUnit и FluentAssertions

Выполнены тесты:
- допустимые и граничные показания;
- недоступность Swagger в Production;
- отклонение POST без CSRF-токена;
- успешный POST с токеном;
- запрет значения выше верхней границы;
- идемпотентность.

Запуск из корня решения:
```powershell
dotnet test EnergyMeter.sln -c Release
```

Тестовый сервер использует `WebApplicationFactory`, не слушает внешний порт
и подменяет аутентификацию тестовым обработчиком с ролью Operator.
Результаты запуска появятся после выполнения команды в среде с .NET 8 SDK.
