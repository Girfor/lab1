# EnergyMeter System — вариант 15

Готовые исходники для Visual Studio 2022 и .NET 8.

## Состав
- `PR3_AuditBaseline` — намеренно проблемный локальный образец для статического аудита (не для Production).
- `PR4_Refactored` — переработанный API с моделью данных, сервисом, авторизацией, CSRF и закрытым Production Swagger.
- `PR6_Tests` — unit и интеграционные тесты xUnit + FluentAssertions.
- `EnergyMeter.sln` — единое решение Visual Studio.

ПР1 и ПР2 — анализ стандартов, программный проект не требуется.
ПР5 — профиль качества для переработанного API.
ПР7 — анализ угроз и защитные механизмы переработанного API.
Э1 — аналитическое эссе.

## Как запустить
1. Установить .NET 8 SDK и Visual Studio 2022 с компонентом ASP.NET.
2. Открыть `EnergyMeter.sln`.
3. В стартовом проекте выбрать `EnergyMeter.PR4.Refactored`.
4. В терминале задать `Demo__Password` для демонстрационного входа.
5. Запустить `dotnet run --project PR4_Refactored`.
6. Протестировать `dotnet test EnergyMeter.sln`.

В Production демо-вход отключен, Swagger не публикуется.
Пример использует оперативную память вместо БД, поэтому данные теряются после перезапуска.

**Проверка исполнения:** в среде подготовки отсутствует установленный .NET SDK.
Компиляция и прохождение тестов должны быть подтверждены после открытия проекта в Visual Studio.
